# 学习状态跟踪 页面版本说明

## 版本基线

- 页面名称: 学习状态跟踪
- 页面文件: 学习状态跟踪.html
- 审查日期: 2026-04-29
- 数据导出版本: v4
- 本地存储键: daily-learning-tracker-state-v4
- 页面形态: 单文件前端页面，依赖 Vue 2、Element UI、ECharts、html2canvas、jsPDF 的 CDN 资源

## 功能清单（代码实装）

### 1. 顶部统一导入导出

- 导出整页 JSON（含学习、Todo、复盘、记账、提醒配置）
- 导入整页 JSON（导入前二次确认）
- 导出 Excel（按当前筛选结果）
- 导出周报 PDF / 月报 PDF
- 记录最近一次导出时间
- 超过 7 天未备份时提醒导出，可 24 小时延后
- 导入文件大小保护（2MB 上限）

### 2. Todo 模块

- 新增、编辑、勾选完成
- 按优先级 + 状态排序
- 已完成任务默认折叠归档，不允许删除
- 明日计划可自动拆分并同步为 Todo

### 3. Overview 总览

- 本周均分、周均时长、待办执行、本月支出、风险项目
- 页面告警（今日缺失、未填日期草稿、连续偏低）
- 最近复盘摘要 + 最近支出摘要
- 填写提醒状态与开关

### 4. 学习记录表

- 日期/时长/项目分/复盘字段统一维护
- 自动补今天记录、生成明天记录
- 动态分组、动态项目列、目标分配置
- 复盘栏折叠/展开，复盘字段可配置
- 筛选: 日期范围、关键词、分组、低分、未补齐
- 排序: 日期升序/降序、时长降序、平均分升序、未补齐优先
- 历史日期锁定、重复日期拦截、草稿行上限控制
- 行复制、行删除、定位今天、新增空白行

### 5. 学习统计

- 按组/按项目两种趋势展示
- 目标线显示
- 低于目标点标记
- 学习热力图、学习时长趋势图

### 6. 复盘信息展览表

- 按天集中展示复盘字段
- 日期范围筛选
- 关键词检索

### 7. 记账本

- 交易新增/编辑/删除
- 历史交易删除二次确认
- 类别管理
- 日历联动记账
- 每周/每月柱状图、类别饼图
- 周期规则自动生成草稿并可确认
- 列表滚动加载

### 8. 建议与提醒

- 自动生成执行建议
- 通知提醒开关 + 提醒时间配置
- 通知权限状态展示
- 通知权限请求失败兜底提示

## 数据结构

### 核心状态

- groups: 分组列表
- projectColumns: 项目列列表（groupId、targetValue 等）
- noteFields: 复盘字段列表
- tableData: 学习记录数据
- todoItems: Todo 数据
- bookkeepingEntries: 记账数据
- bookkeepingCategories: 记账分类
- recurringRules: 周期记账规则
- reminderConfig: 提醒配置

### 学习记录行结构

- id
- date
- durationMinutes
- metrics
- notes

### 记账记录结构

- id
- time
- amount
- item
- category
- reason
- isDraft
- generatedFromRuleId

## 功能关联审查

### 关联正确

- 学习记录表 -> Overview: 今日缺失项、趋势摘要、风险项目、最近复盘均来自 tableData，关联正确。
- 学习记录表 -> 学习统计: 趋势图、热力图、时长图由 tableData 驱动，关联正确。
- 学习记录表 -> 复盘信息展览表: noteFields + tableData 直连，关联正确。
- Todo -> Overview / 记录建议: 统计值、列表、建议文案均来自 todoItems，关联正确。
- 记账本 -> Overview / 日历 / 图表 / PDF: 数据源统一为 bookkeepingEntries，关联正确。
- 导入导出 -> 全页状态: groups、projectColumns、noteFields、tableData、todoItems、bookkeepingEntries、recurringRules、reminderConfig 全量进入快照，关联正确。

### 本次修复与优化（2026-04-29）

- 修复稳定性: 导入文件新增 2MB 上限，降低异常大文件导致页面卡顿风险。
- 修复提醒链路: reminder time 在状态归一化时做格式标准化，避免非法时间值导致提醒逻辑失效。
- 修复权限兜底: Notification 授权请求补充 catch 分支，避免权限请求异常时无反馈。
- 修复交互一致性: 删除分组后自动回退筛选值，避免筛选指向已删除分组造成展示异常。

### 需要注意但未改动

- 导入 JSON 仍为“自用快照”校验强度，不是严格安全边界。
- 关键依赖仍来自公网 CDN，离线或第三方异常会影响可用性。
