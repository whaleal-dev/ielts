# 学习状态跟踪 发布说明

## 发布日期

2026-04-29

## 本次变更

### 修复

- 修复导入链路缺少文件体积保护的问题，新增 2MB 上限校验。
- 修复提醒时间未统一格式时可能导致提醒链路失效的问题。
- 修复通知权限请求异常场景缺少兜底提示的问题。
- 修复删除分组后筛选条件可能指向失效分组的状态不一致问题。

### 交互优化

- 分组删除后自动回退到“全部分组”筛选，避免表格显示与筛选意图错位。
- 通知权限请求失败时给出明确反馈，减少用户误判“提醒已生效”的概率。
- 导入过大文件时直接拦截并提示，避免页面卡顿和误导入。

### 文档与审查更新

- 完整更新版本文档，修正历史描述中与代码不一致的内容（如排序能力已为多种模式）。
- 重新核对“学习记录、Todo、复盘、记账、图表、导入导出”功能关联，结论为主链路正确。

## 审查结论

- 主要功能链路正确: 数据录入、统计图、复盘展览、记账和导入导出保持同一状态源。
- 本次修复集中在稳定性和状态一致性，未改变核心数据模型。
- 页面静态诊断无错误，未发现阻断级问题。

## 已知风险

- 页面仍依赖外部 CDN，离线或第三方不可用会影响加载。
- JSON 导入目前是“自用快照校验”强度，不建议作为不受信输入边界。

## 验证结果

- 已完成静态诊断检查: 无错误。
- 已完成代码级功能核对: 导入导出、提醒、筛选、图表、账本关联路径可追踪。

## 建议的后续版本方向

1. 为导入数据增加 schema 级别校验与版本迁移提示。
2. 将关键 CDN 依赖本地化或补齐完整性校验方案。
3. 增加导入失败详情面板（字段级错误定位），降低排查成本。
