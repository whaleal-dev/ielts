# IELTS Dev v0.2.0 计划

更新时间：2026-09-13

## 1. 版本目标

在 v0.1.0 已完成“今日 → 语料听写 → 学习动态 → 记录复盘”首轮闭环的基础上，v0.2.0 聚焦两个结果：

1. 建立统一错词中心，让语料库听写、单词听写和词汇难词可以在一个入口查看。
2. 将可靠的学习事件扩展到单词听写和只听循环，使今日工作台与学习路径不再只反映语料库训练。

版本完成后，用户应能从今日工作台看到多模块训练事实，从统一错词中心定位近期问题，再回到对应训练模块复习。

## 2. 范围

### 2.1 统一错词只读模型

- 新增共享错词适配层，读取以下既有数据源：
  - 语料库听写 `mistakeBook`。
  - 单词听写 `wrongDict`。
  - 词汇学习 `difficultWords`。
- 使用仅用于聚合展示的规范化词面进行去重：去除首尾空格并转为小写。
- 每条聚合记录保留原始词面、来源模块、来源 key、错误次数／难度、最近时间和可用上下文。
- 不修改、删除或重命名现有 localStorage、IndexedDB key 与字段。
- 单个来源损坏时跳过该来源并给出可理解提示，不影响其他来源展示。

### 2.2 错词中心页面

- 新增 `/mistakes` 一级页面，并从今日工作台与学习路径进入。
- 支持按来源、关键词和状态筛选，默认优先展示近期与高频错词。
- 聚合重复词面时展示全部来源，不静默覆盖来源信息。
- 首版只提供回到来源模块的复习入口，不直接跨模块写回“已掌握”状态。
- 空数据、部分数据损坏和移动端窄屏都有明确状态。

### 2.3 学习事件扩展

- 单词听写接入 `session_started`、`session_completed` 和 `mistake_added`。
- 只听循环接入 `session_started` 与 `session_completed`。
- 事件必须来自现有可靠开始／结束时机；暂停、切词和页面卸载不推测为完成。
- 事件继续使用 `ielts-dev-learning-events-v1`，不在本版变更事件 schema。
- 今日工作台、学习路径和记录复盘统一按新增来源汇总时长、轮次与近期错词。

### 2.4 文档与回归

- 更新模块说明、架构、持久化契约、人工冒烟清单和 `ROADMAP.md`。
- 保留应用完整备份对新增聚合来源的覆盖；错词中心本身不创建第二份持久化数据。

## 3. 明确不做

- 不做账号、后端、云同步和多端冲突处理。
- 不迁移或合并现有模块的错词存储。
- 不在错词中心直接修改来源模块的掌握、删除或难度状态。
- 不新增全局播放、语音和提醒配置。
- 不为没有可靠完成时机的发音、同义词和音频播放器制造推测性学习事件。

## 4. 实施顺序

1. 先为三类旧数据准备脱敏样本，定义错词聚合类型、归一化规则和损坏数据行为。
2. 实现只读适配层与单元测试，验证跨来源去重、排序、字段缺失和单源损坏。
3. 实现 `/mistakes` 页面及导航入口，保持来源模块拥有数据写入权。
4. 为单词听写和只听循环补事件，并验证开始、完成、暂停、停止、重开和路由卸载。
5. 复验今日、学习路径、记录复盘、完整备份与旧数据兼容，再同步文档。

## 5. 验收标准

- 三个来源的同一词面只占一个聚合条目，同时可看到完整来源列表。
- 任一来源为空或损坏时，其他来源仍可正常展示。
- 单词听写完成一轮后，今日工作台显示真实时长、完成轮次和新增错词。
- 只听循环只有完整结束时才增加完成事件，暂停或离开页面不会误记完成。
- 现有旧数据无需迁移即可继续使用，应用完整备份可导出并恢复原模块数据。
- `npm test` 与 `npm run build` 通过。
- 390px、768px、1440px 下 `/mistakes`、今日、学习路径和记录复盘无横向溢出，控制台无未处理错误。

## 6. 主要风险与控制

- 同词异义或词组大小写被错误合并：聚合仅使用规范化词面做展示索引，始终保留来源 key 与原始词面。
- 跨模块直接写回造成状态语义冲突：v0.2.0 保持只读聚合，只跳转回来源模块操作。
- 事件重复写入：每轮只生成一个 session id，完成后立即清空；重开训练必须创建新 id。
- 旧数据异常阻断整个页面：每个来源独立解析、独立报告，不做全有或全无读取。
