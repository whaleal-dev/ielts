## 版本
- 发布名称：语料库雅思单词听写 v2.2
- 发布日期：2026-04-29
- 发布类型：审查修复发布（功能审查 + 细节优化）

## 发布摘要
本次发布聚焦“按版本文档反查功能正确性”，并对主页面做了一轮全文审查。语料内容未改动，主要修复设置回退与导入链路中的细节问题，补齐功能关联说明与风险说明。

## 本次变更
- 修复设置恢复默认值：播放间隔在无历史值时统一回落到 2 秒。
- 修复排序设置迁移：导入备份后可正确保留错词排序 recent（按最近时间）。
- 增强导入可靠性：写入设置时增加 localStorage 异常兜底，失败会给出明确错误并中断流程。
- 增强排序键鲁棒性：恢复配置时仅接受白名单排序值，避免异常值污染 UI。
- 完成主页面功能清单与关联关系复核，并同步到版本文档。

## 审查结论
- 功能正确：章节选择、词库校验、练习流程、错词本、统计、导入导出、音频缓存主链路均可闭环。
- 关联正确：模式切换、统计写入条件、错词筛选与练习入口、导入覆盖刷新关系正确。
- 安全可控：未发现高危注入漏洞和高危本地数据破坏漏洞。

## 风险与边界
- 音频仍依赖第三方 HTTP 源，HTTPS 场景可能受混合内容拦截影响。
- 音频缓存受浏览器跨域策略和上游响应头影响，存在环境差异。
- 本地存储空间不足时，导入或持久化可能失败。

## 回归建议
- 验证“清空浏览器数据后首次进入”是否显示备份提醒。
- 验证“排序方式=最近时间 -> 导出备份 -> 导入 -> 排序仍为最近时间”。
- 验证“存储空间受限”场景下，导入设置失败提示是否可读且不会写入半状态。
