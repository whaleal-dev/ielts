## 基本信息
- 产品名称：语料库雅思单词听写练习页
- 主文件：王璐语料库_源码.html
- 审查日期：2026-04-29
- 当前版本：v2.2
- 版本性质：功能全量审查 + 关联关系校验 + 细节交互优化 + 稳定性修复

## 功能全清单（按模块）
- 词库与匹配：内置 CHAPTER_WORD_SETS 章节词库；支持按章节精确匹配和手动输入自动匹配。
- 输入预处理：按行切分、去空白、转小写、去重，确保练习列表标准化。
- 合法性校验：区分“词库不存在”和“不属于所选章节”两类异常词，并可在开始前自动移除。
- 练习模式：
	- 听写模式：播放 -> 输入 -> 判定 -> 更新统计。
	- 听音模式：仅播放，不记录听写正确率、错词与章节统计。
- 播放能力：支持倍速、间隔、重播、暂停/继续、自动/手动下一题。
- 练习状态追踪：待练、已掌握、本轮错词、当前进度、当前章节匹配来源、缓存数量。
- 错词本系统：自动累积、章节筛选、多选勾选、反选、阈值筛选（低正确率/高错误次数/最近 7 天）、发音试听、删除、CSV 导出、直接练习。
- 单词统计：记录每个词的练习次数和正确次数，用于正确率排序与复习优先级。
- 章节统计：仅在“听写 + 按章节 + 完整章节练习完成”时写入历史，并提供折线图与历史列表。
- 数据备份与迁移：
	- JSON 导出（settings/mistakeBook/wordStats/chapterStats）。
	- 导入预览（覆盖数量对比）。
	- v1/v2 备份迁移与结构清洗。
- 本地存储：localStorage 保存配置与统计；IndexedDB 保存音频二进制缓存。
- 数据管理：支持分别清空错词本、章节统计、练习统计、音频缓存，并有确认弹窗。
- 备份提醒：按 7 天周期提醒导出学习记录。

## 功能关联关系审查（核心链路）
- 章节选择 -> 自动填充单词 -> loadWordSet 校验 -> resetSession 建立练习队列：关联正确。
- 模式选择 -> renderModeControls 控件可用性 -> moveToNextWord / submitAnswer 行为分流：关联正确。
- 判题结果 -> recordWordPractice + upsertMistakeBook -> renderMistakeBook：统计与错词联动正确。
- 会话结束 -> recordChapterPracticeIfNeeded（受模式、章节、完整性约束）-> renderChapterStats：关联正确。
- 错词本筛选/勾选 -> getMistakePracticeEntries -> startSelectedMistakePractice：默认范围与精细选择联动正确。
- 导入预览 -> applyImportedPayload -> loadSettings + render：覆盖流程和刷新链路正确。
- 音频播放 -> 缓存命中/下载缓存 -> 状态提示与缓存计数更新：关联正确。

## 本轮修复与优化（v2.2）
- 修复：设置恢复时播放间隔默认值从 0 秒纠正为 2 秒，和界面默认一致。
- 修复：导入备份时保留错词排序“recent（按最近时间）”，避免被意外回退为错误率排序。
- 修复：导入设置写入 localStorage 增加异常兜底，存储失败时给出明确错误并阻断半成功导入状态。
- 优化：错词排序键恢复逻辑增加白名单校验，降低脏数据导致的 UI 异常风险。

- 未发现高危 XSS/脚本注入点：用户可控内容主要通过 textContent 写入，确认弹窗内容有标签白名单处理。
- 未发现高危数据破坏漏洞：导入有版本和结构校验，清空操作有确认流程。
- 已修复 3 项中低风险问题：默认值不一致、排序设置丢失、导入设置写入缺少兜底。

## 已知边界与风险
- 远程音频依赖 http://www.1kao.com.cn，在 HTTPS 部署场景可能受混合内容策略限制。
- 音频缓存能力受浏览器跨域策略和上游响应头影响，存在环境差异。
- 本地存储容量有限，极端情况下可能触发 localStorage/IndexedDB 写入失败。
