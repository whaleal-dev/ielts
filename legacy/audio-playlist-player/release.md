# 音频顺序播放器 发布记录

## 2026-04-30

### 变更类型
- 交互优化
- 稳健性修复
- 安全细节加固
- 功能关联审查
- 文档增强

### 代码变更
- 新增悬浮状态消息芯片：播放、暂停、导入、错误等关键动作有即时可见反馈。
- 新增空格键快捷控制：在非输入控件聚焦时支持播放/暂停/继续。
- 优化时间标签：
  - `timeupdate` 在无效时长场景也刷新当前时间显示。
  - 章节组合播放（sequence）补充时间标签更新，避免信息“静止”感。
- 强化音量输入：对滑块值进行 0-1 数值钳制后写入播放器。
- 强化资源回收：页面卸载前统一清理计时器和对象 URL。
- 安全细节加固：系统章节列表与选择 chips 中的 `data-*` 属性值增加转义，降低属性注入面。
- 选择摘要优化：已选章节摘要默认展示前 6 项并省略，避免长文本挤压布局。

### 功能关联审查结果
- 主体脚本和增强脚本的覆盖链路正确，初始化顺序正常。
- 系统章节导入、本地上传、历史缓存都可汇入统一播放队列模型。
- 普通音频播放与章节组合播放在同一播放器上分工清晰，拦截边界明确。
- 全局配置与条目级配置联动逻辑正确，播放中编辑当前项可即时生效。

### 全文审查结论
- 细节与交互：状态反馈、快捷控制、章节播放反馈一致性得到提升。
- bug：未发现新增功能回归，且修复了章节 UI 属性转义和时间反馈细节问题。
- 安全：未发现高危漏洞；现阶段主要风险为静态页未启用 CSP（公网部署时建议补齐）。

### 回归建议
- 播放中执行“上移/下移/复制/删除当前项”并观察当前项指针。
- 章节组合播放中执行暂停/继续/停止并观察进度与时间标签。
- 历史缓存批量导入、刷新、清空后再播放，确认缓存与当前清单解耦。

## 2026-04-29

### 变更类型
- 修复
- 交互一致性优化
- 文档补充
- 功能审查
- 安全审查

### 代码变更
- 统一播放项输入约束与全局默认配置：
  - 自定义倍速输入范围调整为 0.6-2.0，步进 0.2。
  - 自定义次数输入范围调整为 1-10。
- 修复删除文件后的播放状态/索引问题：
  - 删除目标文件对应条目后，若影响当前队列位置，自动修正 currentIndex。
  - 删除正在播放的文件后，停止播放并刷新音频库与播放清单，避免 UI 与状态不一致。
- 修复删除播放项时的队列索引漂移：
  - 删除当前播放项之前的条目时，同步回退 currentIndex。
- 修复播放中移动播放项时的索引漂移：
  - 当前播放项被上移或下移时，currentIndex 同步到新位置。
  - 其它条目跨越当前播放位置时，currentIndex 按实际队列位置补偿。
- 修复播放中复制条目时的索引漂移：
  - 当复制发生在当前播放项之前，currentIndex 自动加 1，保持当前播放项不变。
- 优化当前播放项的实时联动：
  - 修改当前项倍速或“跟随全局倍速”后，播放器实时更新 playbackRate。
  - 修改当前项次数或“跟随全局次数”后，循环进度标签立即刷新。
  - 修改当前项音频源后，播放器立即切换到新音源继续当前条目。

### 功能联动审查结果
- 主页面脚本与增强脚本的函数覆盖关系正常，初始化顺序正确。
- 系统章节导入链路可落到统一播放队列模型，与本地音频逻辑兼容。
- 全局配置与条目级配置联动生效正确，跟随全局逻辑正确。
- 文件库、播放清单、状态面板均由统一状态驱动，未发现平行状态源导致的不同步问题。
- 组合章节播放对 `audio` 的 `ended/timeupdate` 拦截只在组合播放项生效，未破坏普通音频播放路径。

### 全文审查摘要
- 细节表现：移动端断点、按钮禁用态、状态反馈文案、空状态提示均完整。
- 交互改进：播放中编辑当前项配置后，当前播放行为现已和 UI 保持同步。
- bug 结论：本次修复前主要问题集中在“播放中编辑队列或当前项”导致的索引/状态漂移；已完成修复。
- 安全结论：未发现高风险漏洞；动态文本已做转义，未发现明显 XSS 注入路径。

### 风险与兼容性
- 本次变更不引入新依赖。
- 变更集中在前端状态与输入边界，兼容现代浏览器。
- 未发现新增语法错误。
- 由于未做自动化播放回归，仍建议在浏览器中手动验证一次“播放中移动/复制/切换当前项音频源”的行为。
