# 音频顺序播放器 功能版本说明

## 2026-04-30 功能生成与审查补充

### 由页面实现生成的功能结构（对照源码）
- UI 布局层：Hero 说明区、上传库、历史库、全局配置、播放清单、悬浮播放条。
- 数据状态层：`state.files`、`state.historyFiles`、`state.playlist`、`state.currentIndex`、`state.sequenceRuntime`、`state.systemSelection`。
- 核心播放层：
  - 普通音频：单 `audio` 元素按条目顺序/循环/随机推进。
  - 组合音频（章节导入）：通过增强脚本将章节切分段（segments）串行播放，并支持段间隔。
- 持久化层：IndexedDB 历史缓存（上传文件二次复用、单条删除、全部清空）。
- 配置层：全局倍速/次数、条目级覆盖、跟随全局开关、自动暂停计时器、播放模式切换。

## 页面定位
- 单文件本地播放器，核心能力是“本地音频 + 可编辑播放清单 + 逐项顺序播放 + 条目级参数覆盖”。
- 页面主体负责本地文件、基础队列、定时暂停、播放器状态机。
- 增强脚本负责系统章节导入、组合音频序列播放、章节搜索与批量导入。

## 功能清单（HTML 主体 + 增强脚本）
- 本地音频库管理：多选上传、拖拽上传、移除单个文件、清空全部。
- 播放清单管理：自动生成条目、手动新增、复制、删除、上移、下移。
- 全局配置：
  - 默认倍速：0.6-2.0，步进 0.2。
  - 默认次数：1-10，步进 1。
  - 自动暂停：按分钟设置，0 表示关闭。
- 播放项配置：
  - 可选择音频源。
  - 可单独设置倍速与次数。
  - 支持切换为“跟随全局倍速/次数”，默认不勾选。
- 播放控制：开始、暂停、继续、停止并重置，包含循环进度、队列进度、进度条、倒计时状态。
- 播放中联动：
  - 当前播放项修改倍速时，播放器倍速即时同步。
  - 当前播放项修改播放次数时，循环标签即时同步。
  - 当前播放项切换音频源时，立即切换到新的音频源继续当前条目播放。
  - 播放中移动或复制队列条目时，当前队列索引会同步修正，避免“显示项”和“实际播放项”错位。
- 系统章节导入（由增强脚本注入）：
  - 听力语料库章节导入。
  - 雅思真经单词章节导入。
  - 支持搜索、全选当前结果、清空当前库选择、统一导入。
  - 章节内词条按顺序播放，间隔 0.5-5 秒，步进 0.5 秒。

## 关键状态与控制链路
- `state.files`：统一维护本地文件与系统导入的组合文件项。
- `state.playlist`：播放清单源数据，条目只保存文件引用与播放配置。
- `state.currentIndex` / `state.currentLoop` / `state.activeItemId`：当前播放位置、重复次数和高亮条目。
- `audioPlayer`：唯一真实播放器，所有播放推进都通过它的 `ended` / `timeupdate` 事件驱动。
- `system_library_enhancer.js` 通过覆写 `renderFileLibrary`、`renderPlaylist`、`playCurrentItem`、`removeFile` 等全局函数，把“系统章节组合播放”接到同一状态机上。

## 文件与功能关联关系
- 音频顺序播放器.html：页面结构、核心状态机、基础播放逻辑、基础渲染与事件绑定。
- system_listening_audio_data.js：听力章节音频元数据源。
- system_word_audio_data.js：单词章节音频元数据源。
- system_library_enhancer.js：
  - 注入“系统章节导入”UI。
  - 覆盖基础渲染与播放函数，扩展组合播放项（sequence）能力。
  - 拦截并增强 ended/timeupdate 行为，使章节内多段音频串行播放。

- 配置关联正确：全局值与播放项“跟随全局”逻辑一致，生效链路正确。

## 全文审查结果

### 细节与交互优化结论
- 输入边界整体合理：全局倍速/次数与条目级倍速/次数已统一到同一 clamp 规则。
- 移动端适配合理：`1024px` 与 `760px` 两个断点能覆盖平板与手机场景。
- 反馈完整：上传、导入、删除、暂停、恢复、播放失败、自动暂停均有状态文案。
- 当前播放项联动已补强：编辑当前播放项时，播放器不会再停留在旧配置或旧音频源上。
- 队列编辑一致性已补强：播放中上移、下移、复制条目后，当前播放索引不再漂移。

### bug 审查结论
- 已修复：删除文件后若影响当前播放位置，`currentIndex` 会同步回退。
- 已修复：删除播放项时若删除的是当前项之前的条目，`currentIndex` 会同步修正。
- 已修复：播放中移动队列条目时，当前播放索引与真实播放项可能错位的问题。
- 已修复：播放中复制当前项之前的条目时，当前播放索引可能偏移的问题。
- 已修复：播放中修改当前项文件/倍速/次数时，播放器状态未即时同步的问题。
- 未发现：空文件引用直接播放导致的未处理异常。
- 未发现：系统章节组合播放与普通音频播放互相污染状态的问题。

### 安全与漏洞审查结论
- 未发现高风险漏洞。
- 动态插入到 HTML 的可变文本均经过 `escapeHtml` 转义，降低了拼接型 XSS 风险。
- 播放资源来源主要是本地 `blob:` URL 与仓库内静态文件，未引入第三方脚本或远程执行链路。
- 未发现 `eval`、`innerHTML` 注入用户原始文本后不转义的路径。
- 残余注意点：页面是纯静态 HTML，未配置 CSP；当前实现主要面向本地受控使用场景，这一风险可接受，但若未来上线到公网，建议补 CSP 与更严格的资源白名单。
