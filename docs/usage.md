# 使用指南

本指南按 2026-10-10 工作区代码核对，2026-10-11 补充新版复核后的恢复、语音和统计行为，包含单词、听力、同义词、单词播放四个模块。启动方式见 [项目首页](../README.md) ，当前发布与验收状态见 [路线图](../ROADMAP.md) 。

## 通用操作与保存

顶部导航切换模块，右上角显示北京时间日期，每分钟刷新；设置图标暂未开放。选择控件支持搜索，听力分组多选可勾选、显示标签和清除，无需按住 Command／Ctrl。

词库上传和粘贴在当前浏览器内处理，学习记录不上传服务器。请固定使用同一访问地址和浏览器：`file://`、`localhost`、`127.0.0.1`、不同端口与不同浏览器的记录不能自动共享。清除网站数据会失去个人词库与学习记录，当前不提供学习记录备份、导入或导出。

页面顶部显示保存状态。保存失败时保留当前页面，使用「重试保存」；同义词与单词播放首次读取失败时显示「重试读取」，成功恢复前不开放编辑和播放。听力读取失败时仍可临时练习，但不保存，需先「重试读取」恢复已有记录；同来源旧记录读取失败也按读取错误处理。无法打开 IndexedDB 时使用 localStorage，并显示兼容存储提示。详细存储约束见 [架构说明](architecture.md#浏览器存储) 。

## 单词学习

「我的词库」固定保留雅思主题词汇，并展示个人词库。内置词库按章节、分组学习，个人词库按导入分组学习；各自保存笔记、难度、掌握状态和学习位置。

### 上传个人词库

点击「上传词库」选择或拖入一个 UTF-8 CSV／TXT，预览后确认保存。单文件最多 2 MiB（2 × 1024 × 1024 字节，界面标为 2 MB），去重后最多 5000 个词条。允许 UTF-8 BOM；无效编码、空文件、缺必填内容或超限均拒绝。

CSV 必须有「单词」「释义」表头，可选「音标」「分组」，按列名读取；使用英文逗号分列，字段内逗号与换行需用双引号包裹。

```csv
单词,释义,音标,分组
environment,n. 环境,/ɪnˈvaɪrənmənt/,环境
take part in,参加,,常用词组
```

TXT 无表头，每行一个词条，按「单词 | 释义 | 音标 | 分组」填写，尾部可选字段可以省略；填分组而不填音标时保留空字段。

```text
environment | n. 环境 | /ɪnˈvaɪrənmənt/ | 环境
take part in | 参加 | | 常用词组
sustainable | adj. 可持续的
```

同一分组内规范化英文、释义与音标全部相同的词条去重。同词不同释义或音标保留，不同分组分别保留。全文件未填分组时，去重后按原顺序每 50 词一组；部分填写时，空分组归入「未分组」。

「文件格式示例」提供实际解析结果及两个下载模板。重名上传自动追加序号，创建独立词库；删除个人词库需要确认，仅清除目标词库及其学习记录，已产生的每日汇总保留。完整格式、错误提示与验收约定见 [个人词库方案](../WORD_LIBRARY_PLAN.md) 。

### 学习、复习与统计

- 提供单词卡片、中文选择题、听音拼写和自动播放。个人词条优先完整匹配本地 MP3，无匹配时使用 Web 英文语音；已有 MP3 播放失败时提示并暂停。
- 「播放设置」默认收起，展开后选择英文发音人，设置 0.6～2 倍速、0～5 秒间隔、每词 1～5 次。默认 Google 英语语音优先，同类候选英音优先；手动选择会保存，暂不可用时发音使用默认英语语音，原选择可用后自动恢复。本地 MP3 速度即时调整，Web 语音参数在下一次发音生效。
- 单词难度为 0～10，新词默认 0；提供「－1」「＋1」「难度＋3」。选中文或听音拼写答错自动＋3，最高 10，同题重复提交不重复加分；答对或标记已掌握不自动减分。
- 「我的笔记」默认展开，可收起，编辑后自动保存。新笔记上限为 400 个 UTF-16 代码单元，已保存的长笔记保留。
- 隐藏单词与隐藏释义开关保留占位，切词、切组与刷新后恢复设置；隐藏单词同时隐藏音标，仍可发音。
- 搜索支持英文、中文释义和音标，跟随当前词库。「难度复习」提供独立搜索、难度上下限、全部／到期筛选与排序，默认展示难度 1～10；最低难度设为 0 可查看难度 0 的词。
- 复习列表可直接调整难度，单词点击与整组练习使用当前筛选结果，到期练习也遵守搜索与范围。增加难度立即到期，降至 0 后退出到期复习；答对按 12／24／72／168／360 小时逐步安排复习。
- 本轮掌握进度按当前练习词表统计已学、已掌握和当前词状态。词库掌握度按当前词库计算，每日学习、最近 7／30 天与连续学习汇总全部词库，统一按北京时间；保持同一词跨午夜继续学习时，新一天正常计入。导入不计学习，删除不回扣每日汇总。
- 开发阶段不读取旧整包单词记录，也不转换旧难词标记；当前难度、笔记与复习进度按逐词记录保存。

## 听力语料库

语料来自 [corpus.json](../listening-word/data/corpus.json) ，包含 Chapter 3、4、5、8、11 的 88 个分组；分组内去重后 9330 条。使用本地原声音频，缺失时明确提示或跳过，不能使用 Web 合成语音替代。

- 选择分组后可直接练习，或在「查看或调整本组语料」编辑当前内容；该区和「播放设置」默认展开。语料以中文分号紧凑显示，输入兼容换行、中英文分号与逗号，优先匹配词库中完整的含逗号语料，保留词组空格并去重。
- 词库不存在、不属于所选分组或缺少音频的语料分别提示；播放失败可重播或跳过，跳过不计为答错。
- 听音模式支持顺序／乱序、每词重复与整轮循环；次数为正整数，没有 20 次上限。单词和词组可分别设置 0.4～2 倍速，间隔为 0～60 秒。
- 间隔为 0 时手动继续；听写答对仍自动进入下一条。暂停会暂停音频和计时。
- 听写按 Enter 提交；答错、显示答案或音频结束后超时均记为错词。下一题清除上一题反馈，支持本轮错词复练。
- 听音当前词与本轮语料列表分别控制显示，首次默认隐藏；「本轮进度」默认展开，可收起。开关会保存，切换不改变播放与计时状态。
- 错词本支持分组多选、搜索、低正确率／多次错误／最近 7 天筛选、排序、多选试听及复练，错误等级可手动调整。
- 只有完整分组听写全部完成才计入章节成绩，按分组和北京时间日期汇总练习次数、累计正确率、最好与最近成绩。听音、子集、错词复练及包含音频跳过的练习不计入。
- 刷新恢复设置、自定义语料、错词与成绩，正在播放的轮次需重新开始。同来源可以读取原听力设置与统计，保留原键；浏览器数据库不缓存音频二进制。

## 同义词

首次无已保存词库时自动加载「同义词-听力179考点词」默认示例，共 179 组、672 个词条，不占文件缓存名额。搜索匹配任意词条，结果保留完整分组。

### 导入与缓存

TXT 使用 UTF-8，无标题行，每行一组，用英文或中文逗号分隔，空行忽略；保留英文词组和中文标签。例如：

```text
environment, surroundings, setting
take part in，participate in，参与
情绪词, happy, cheerful, test测试
```

「示例词库」旁的「示例文件」提供逗号分隔、英文词组与中英标签三种教程，直接对照文件内容与实际解析分组。含汉字词条只展示，不参加发音；「test测试」以及「𠮷」等扩展汉字也会被排除。单个词条最多 200 个字符。

页面主要说明 TXT；解析器和文件选择器同时保留 JSON 支持，格式为字符串二维数组。这里的词库导入不包含学习记录恢复。

| 限制 | 上限 |
| --- | --- |
| 单个文件 | 2 MiB，界面标为 2 MB |
| 每批新上传与所选缓存文件合计 | 10 MiB |
| 当前合并词库 | 10000 个词条，含仅展示的中文标签 |
| 单组 | 200 个词条 |
| 组内每页 | 50 个词条，播放自动跟随当前词所在页 |
| 已缓存文件 | 20 个 |

多文件按选择顺序合并，替换当前词库。缓存多选按弹窗列表显示顺序合并，新上传文件追加在后面；任一文件编码、格式或合并规模不合格，整批拒绝并保留当前词库与缓存。

成功上传的文件分别缓存。同名文件替换并排到最新，超过 20 个淘汰最早文件；选择缓存不改变淘汰顺序。手动删除缓存只删除该文件的目录项与内容块，已加载词库和笔记保留。保存失败不会显示已缓存，可关闭导入弹窗后使用顶部重试入口。

### 播放与笔记

- 词库操作、播放设置与播放控制在同一张卡片；支持英文发音人、0.5～2 倍速、0～5 秒间隔，每词播放与每组循环均可选 1／2／3／5／10。
- 每组完成设定轮数后进入下一组；点击英文词条试听，自动播放中点击词条从该词继续。循环队列按位置和轮次推进，不随循环次数复制全部词条。
- 「播放行居中」默认关闭，开启后当前词所在组立即居中，并跟随播放和切词；选择会保存，切换不打断播放，弹窗打开时不滚动背景。
- 提供上下词、播放／暂停、高亮，以及已有笔记展示、编辑与移除；没有新增笔记入口。
- 词库、缓存、设置、笔记与位置刷新后恢复，刷新不自动发音；暂停后继续会从当前词重新播放。调整发音人、倍速、间隔或播放次数会暂停播放，居中开关独立保存。

## 单词播放

- 粘贴英文单词或词组，按中英文逗号或换行解析，过滤含中文词条，按大小写与连续空白规范化去重，显示过滤与重复数量。单个词条最多 200 个字符，页面输入框最多 100000 个 UTF-16 代码单元。
- 使用 Web 英文语音，默认 Google 英语语音优先，同类候选英音优先，无 Google 时英音优先；保留可用的手动选择，支持语音列表延迟加载。旧百度设置恢复为 Web 语音。
- 提供 0.5～1.5 倍速、每词 1～5 次、0.5～5 秒间隔；顺序播放完本轮停止。支持暂停、重播、上下词、点击列表跳转和一键乱序，乱序重置位置。
- 听写模式隐藏当前词和列表拼写，逐词重复后等待输入，检查答案忽略大小写与连续空格，也可显示答案；检查后手动切换下一词。
- 词表、设置、位置与完成状态刷新后恢复，刷新不自动发音。暂停后继续从当前词重新播放，调整播放设置会暂停。
- 「清空词表与设置」需要确认，仅清空当前模块的新版词表与设置，原参考页记录保留。Web 语音失败时显示错误并停止，可重播或换发音人。

同义词与单词播放的上下词、点击词条和重播会试听，但不会开启原本关闭的自动播放；点击播放按钮或使用播放快捷键才主动开启。

两模块保留已保存的发音人选择；语音列表尚未加载该选择时，播放临时使用默认英语语音，可用后自动恢复。单词播放的中文过滤也包含扩展汉字。

这两个模块底部显示「建议使用 Google 浏览器＋VPN」，进入时对非 Chrome 提示「请使用 Google 浏览器」。同来源共用提醒日期，按北京时间自然日最多一次；不能保存提醒日期时只保留底部建议。该识别用于提醒，浏览器标识可能被伪装，也不能保证 Web 语音一定可用。

## 快捷键

| 模块 | 按键 | 行为 |
| --- | --- | --- |
| 单词学习 | 左／右方向键 | 上一词／下一词，仅学习视图生效 |
| 单词学习 | 空格 | 自动播放／暂停 |
| 听力 | 上方向键 | 重播当前语料 |
| 听力 | 左／右方向键 | 听音上一条／下一条；听写已判题后右方向键可继续 |
| 听力 | 空格 | 暂停／继续，仅活动练习生效 |
| 听力 | Enter | 答案输入框内提交，已判题时表单进入下一条 |
| 同义词 | 左／右方向键、空格 | 上下词、自动播放／暂停 |
| 单词播放 | 左／右方向键、空格、`R` | 上下词、播放／暂停、重播 |

全局快捷键忽略 Ctrl／Meta／Alt 组合、已处理事件、输入与选择控件、按钮、链接和打开的弹窗，保留浏览器操作。听力表单的 Enter 属于输入框操作。Windows 原生组合键验收状态见 [代码审查记录](../CODE_REVIEW.md#audit-008快捷键拦截带修饰键的组合) 。
